# Gate.io Spot Pro Scalper — Kivy / Android

تطبيق Gate.io Spot يعمل في سوق Spot فقط. الواجهة الحالية ووظائف الإعدادات والتنبيهات وسجل الصفقات وحساب Paper محفوظة. الوضع الافتراضي بعد التطوير هو Paper، ولا يُسمح بإرسال أوامر Live قبل اجتياز التحقق التاريخي والتجريبي وتفعيل موافقة مستقلة.

## الاستراتيجية الافتراضية المطورة

- إطار الدخول: 5m؛ تأكيد الاتجاه: 15m و1h. يظل الحد الأقصى للاحتفاظ 15 دقيقة، ما يناسب السكالبينج السريع مع تقليل ضوضاء إطار الدقيقة.
- EMA 9/21/200 مع اشتراط تقاطع صاعد حديث، ترتيب المتوسطات، وميل EMA21.
- السعر فوق Daily VWAP، مع Volume Surge وZ-Score على شمعة الدخول المغلقة نفسها.
- Wilder RSI(14) ضمن نطاق 52–68، شمعة صاعدة وإغلاق قريب من القمة، ومنع مطاردة السعر إذا ابتعد أكثر من 0.8 ATR عن EMA9.
- مخارج ATR: هدف ووقف متكيفان مع التقلب، حماية تعادل بعد احتساب تقديري للرسوم والانزلاق، وقف متحرك وخروج زمني عند 15 دقيقة.
- مراقبة المراكز في خيط مستقل عن دورة مسح العملات حتى لا يتوقف فحص الأسعار طوال فترة فحص السوق.

## الاختبار التاريخي الحقيقي

يقرأ `backtest.py` شموع 5m و15m و1h التاريخية العامة من Gate.io API v4. تم اختيار إطار 5m للدخول لأن Gate.io يقيّد الرجوع إلى 10,000 نقطة لكل إطار؛ 26 يومًا من شموع الدقيقة يتجاوز هذا القيد، بينما يسمح 5m بعينة أطول. يستخدم الشمعة التالية للدخول لتجنب تعبئة افتراضية عند إغلاق الشمعة التي أنتجت الإشارة. يخصم رسومًا لكل جانب وانزلاقًا سلبيًا لكل جانب. وعند لمس الوقف والهدف في الشمعة نفسها يفترض تنفيذ الوقف أولًا، وهو افتراض محافظ.

تشغيل محلي:

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
python backtest.py --days 26 --pairs BTC_USDT,ETH_USDT,SOL_USDT,XRP_USDT --fee-pct 0.10 --slippage-bps 5
```

يُقسّم الاختبار زمنيًا إلى 70% تدريب و30% خارج العينة. يصدر `backtest-results/backtest_report.json` و`backtest-results/backtest_trades.csv`. معيار النجاح الافتراضي لجزء خارج العينة: 30 صفقة على الأقل، نسبة فوز 60% على الأقل، Profit Factor لا يقل عن 1.05، ربح صافٍ موجب، وتراجع أقصى لا يتجاوز 10%.

محدودية مهمة: المحاكي يختبر كل زوج بصورة مستقلة؛ لا يحاكي بعدُ سقف الصفقات المفتوحة المشترك أو رصيدًا واحدًا عبر جميع الأزواج. لذلك تقريره بوابة تحقق أولية، وليس ضمانًا للربحية أو موافقة نهائية على Live. كما أن 0.10% رسوم كل جانب و5 bps انزلاق كل جانب قيم افتراضية قابلة للتغيير وليست تعرفة حسابك المؤكدة.

يعمل GitHub Actions تلقائيًا على الاختبارات ثم الاختبار التاريخي، ويرفع التقرير ضمن Artifacts حتى لو لم تجتز النتائج معايير القبول. لا يتم تفعيل التداول الحقيقي تلقائيًا عند نجاح الاختبار؛ يجب أولًا تشغيل Paper لفترة ممتدة ومراجعة النتائج التنفيذية والانزلاق الفعلي.

## بناء APK

من تبويب Actions شغّل `Build Gate.io Spot Pro Scalper APK`، ثم نزّل `gateio-spot-pro-scalper-apk` من Artifacts عند نجاح البناء.

## إعدادات البناء

Kivy + Buildozer، مع Python 3.11 في CI وAndroid API 33 وarmeabi-v7a.
